# 奶油小铺 · PIXEL CAKE STUDIO

一个三步完成的像素蛋糕小游戏：挑蛋糕胚 → 抹奶油 → 放装饰，最后把成品存成一张像素风蛋糕卡片。

纯原生 HTML + CSS + Canvas 2D，没有构建工具、没有外部依赖、没有网络请求。所有蛋糕和装饰都是代码逐像素画出来的。

## 快速开始

**双击 `start.bat`**，它会启动本地服务器并自动打开浏览器。按 `Ctrl + C` 停止。

也可以手动启动：

```powershell
cd d:\VibeCoding\cake-studio
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

然后访问 <http://localhost:8090/>。端口被占用时会自动顺延（8090–8109），以窗口里打印的地址为准。

支持桌面和手机。手机建议使用 Chrome / Safari / Edge 最新版。

## 怎么玩

1. **蛋糕胚**：开局盘子上已经有一块香草蛋糕胚，直接进入下一步也可以；把香草 / 抹茶 / 巧克力蛋糕胚拖到盘子上可以替换，或者点一下卡片直接换口味。
2. **抹奶油**：选奶油口味和笔刷大小，在蛋糕上按住涂抹。覆盖率到 **55%** 后可以进入下一步。
3. **装饰**：把草莓、蓝莓、樱桃、蜡烛等拖到蛋糕上；点装饰卡片也能直接放上去。点画布上的装饰可以选中、移动或删除。
4. **完成**：至少放一个装饰后点「完成蛋糕」，可以保存一张 3 倍分辨率、带边框和日期的 PNG。

快捷键：`Ctrl/Cmd + Z` 撤销当前步骤操作，`Delete` 删除选中的装饰，`Esc` 关闭成品卡。

## 实现说明

- **像素画渲染**：逻辑画布固定 480×320，所有形状用整数坐标、硬边扫描线绘制，CSS 放大时使用 `image-rendering: pixelated`，不产生抗锯齿。
- **蛋糕**：程序化绘制顶面椭圆、圆柱侧面、夹层、海绵颗粒和 1px 描边；三种口味共用几何，只换调色板。
- **奶油**：预渲染 4 色 × 3 尺寸 × 3 纹理的像素笔刷；涂抹时按指针轨迹连续盖章。奶油用蛋糕轮廓遮罩裁剪，覆盖率按遮罩内像素统计。
- **装饰**：12 种装饰用 ASCII 像素图 + 调色板定义，启动时生成精灵；蜡烛有三帧火焰闪烁。拖放、点击、再次移动和删除都通过一份数据列表驱动。
- **交互**：Pointer Events 统一鼠标和触摸；卡片拖拽有跟手幽灵图，手机端自动上移避免挡住手指。
- **成品导出**：把画布按 3 倍最近邻放大，合成纸色边框和日期，导出 PNG data URL。
- **服务器**：零依赖 PowerShell HttpListener 静态服务器，正确返回 UTF-8 和静态资源 MIME。

## 想改点什么

- **口味 / 颜色**：`game.js` 顶部的 `BASE` 和 `CREAMS`。
- **装饰**：`DECO_DEFS` 里的 ASCII 像素图，每个字符对应 `palette` 中的一个颜色。
- **奶油门槛**：`const GOAL = 0.55;`
- **笔刷大小**：`BRUSH_RADII`。
- **画布尺寸**：`W` / `H` 和 `CAKE` 几何参数；如果改比例，记得同步 CSS 的 `aspect-ratio`。
- **服务器端口**：运行 `server.ps1 -Port 8095`，或修改文件开头的默认值。

所有图像都是本地程序化生成，没有外部图片或字体请求，离线也能玩。
